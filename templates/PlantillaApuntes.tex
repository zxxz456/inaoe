\subsection{Un subtema dentro de la sesión}

Ecuación numerada, para poder referirla después:
\begin{equation}\label{eq:ejemplo}
  \sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\end{equation}

En la ecuación~\eqref{eq:ejemplo} la suma es cuadrática en $n$.

Varios pasos alineados por el signo igual:
\begin{align}
  T(n) &= 2\,T\!\left(\frac{n}{2}\right) + n \\
       &= 2\left(2\,T\!\left(\frac{n}{4}\right)
          + \frac{n}{2}\right) + n \nonumber \\
       &= 4\,T\!\left(\frac{n}{4}\right) + 2n
\end{align}

\begin{ejemplo}
  Un ejemplo resuelto en el pizarrón.
  \begin{enumerate}[label=\arabic*., itemsep=0.2em]
    \item Primer paso.
    \item Segundo paso.
  \end{enumerate}
\end{ejemplo}

Código pegado tal cual, con el lenguaje que sea:

\begin{lstlisting}[language=C,caption={Búsqueda binaria}]
int buscar(int arr[], int n, int objetivo) {
    int izq = 0, der = n - 1;
    while (izq <= der) {
        int medio = izq + (der - izq) / 2;   /* evita desbordar */
        if (arr[medio] == objetivo) return medio;
        if (arr[medio] < objetivo) izq = medio + 1;
        else der = medio - 1;
    }
    return -1;
}
\end{lstlisting}

Y cuando lo que se copia del pizarrón es el algoritmo y no el
programa, va como pseudocódigo. Se numera por sesión igual que los
teoremas, así que se puede referir con \verb|\ref|:

\begin{algorithm}[htbp]
  \caption{Búsqueda binaria}
  \label{alg:ejemplo}
  \begin{algorithmic}[1]
    \Require arreglo ordenado $A[1 \ldots n]$, valor $x$
    \Ensure el índice de $x$ en $A$, o $-1$ si no está
    \Procedure{BusquedaBinaria}{$A, n, x$}
      \State $\mathit{izq} \gets 1$
      \State $\mathit{der} \gets n$
      \While{$\mathit{izq} \le \mathit{der}$}
        \State $m \gets \lfloor (\mathit{izq} + \mathit{der}) / 2
               \rfloor$ \Comment{no desborda}
        \If{$A[m] = x$}
          \State \Return $m$
        \ElsIf{$A[m] < x$}
          \State $\mathit{izq} \gets m + 1$
        \Else
          \State $\mathit{der} \gets m - 1$
        \EndIf
      \EndWhile
      \State \Return $-1$
    \EndProcedure
  \end{algorithmic}
\end{algorithm}

El algoritmo~\ref{alg:ejemplo} corta el espacio de búsqueda a la mitad
en cada vuelta. Las palabras clave se escriben en inglés
(\verb|\While|, \verb|\If|, \verb|\Return|) y salen impresas en
español; las dos que no trae el paquete son \verb|\Hasta|, para el
\verb|\For|, y \verb|\Intercambiar|.
