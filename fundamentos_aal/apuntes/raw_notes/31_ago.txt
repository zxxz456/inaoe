-- IR models basados en modelos de lenguaje --

Un modelo de lenguaje estadistico asigna una probabilidad a una secuencia de m palabras
por means de una deistribucon de probabilidad

    p(t1,t2,t3,t4) = p(t1)p(t2|t1)P(t3|t1t2)...

La forma mas simple de que un ML deseche un contesto probabilistico es 
tratar cada termino de manera independiente, esto sirve por si no hay mucho
contexto, se llama secuencia de unigramas

Pero de donde se sacan esas probabilidades?

Antes de entrar a como se usan en recuperacion de info... un ML se usa en el dia a dia
como en los autocompletados, traducion de texto, correccion otrografica, reconocimeinto de habla

pero como s usan los ML en IR?

La ide principal es que los documentos pueden ser rannkeados en su similitud de generar
la query

a cada doc lo voy a ver como si fuese un mundo... algo independinete y sobre ese doc s calcula
o se construye un LM. Y cuando llega un query se hace la pregunta de, cual es la probabilidad de
generar la secuencia de la query a partir de cada modelo de lenguaje

    P(Q|Mdi)

El objetivo es rankear docs by P(d|Q), donde la probabilidad de un docuento es interpreteada como 
la similitud que es relevante a la query

    p(di|Q) = P(Q|di)p(di)/p(Q) aprox p(Q|Mdi)

Pero que pasa cunado veo un termino nuevo... la probabilidad se iria a cero

Para solucionar esto, se asume que los termino no vistos se vieron 1 vez 

pero una forma mas robustas es agregar un modelo de lenguaje para toda la coleccion 
completa, es una mezcla entre el documento y la coleccion 

{formula p(d|q) alpha p(d)...}

P(d) s la confiaanza - como la probabilidad de ser recuperado
